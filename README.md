# EECE7398-Team4-Project

Shared repository for the EECE7398 Team 4 final project. It holds our plans and ideas, our reference material, and each member's own work.

## Layout

```
.
├── plans-and-ideas/      proposal, reviews, meeting notes, project guide
├── references/           papers and other reference material
└── members/              one folder per member
    ├── Pssumu/
    ├── alemarefanim/
    ├── Jan-Zhao11/
    └── Yeyaohui11/
```

## How we work

- **Your own folder:** put your work in `members/<your-github-username>/`.
- **Other members' folders:** feel free to read and download anything. To build on someone else's file, copy it into your own folder, or just ask them.
- **Shared folders:** `plans-and-ideas/` and `references/` are for everyone. Give the team a heads-up before you make big changes there.
- **Pull and push:** run `git pull` before you start and before you push.

## Everyday git

```bash
git clone https://github.com/Pssumu/EECE7398-Team4-Project.git   # first time only
git pull                                                         # before you start
git add members/<your-github-username>/
git commit -m "what changed"
git push
```

## Good to know

- This repository is **public**, so don't commit passwords, keys, or personal data.
- Git can't merge Word or PDF files. Avoid editing the same file at the same time as someone else.
- Keep files under 50 MB. GitHub rejects files over 100 MB.
- AI agents working in this repo should read [AGENTS.md](AGENTS.md) first.
